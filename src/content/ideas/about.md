## Tech Stack

This website is built using the following technologies:

- **Astro.js**: A modern static site generator that allows for fast and optimized web development
- **Decap CMS**: A content management system that provides an easy-to-use interface for managing website content
- **GitHub**: Used for version control and hosting the website's source code
- **Decap Bridge**: A service that connects Decap CMS with GitHub for seamless content management

## Features

The site includes several key features:

- Static site generation for optimal performance
- Git-based content management workflow
- Responsive design with Tailwind CSS
- Custom earth-tone design system
- SEO optimization with structured data
